# 图词岛 · Picture Words

一个面向移动设备的看图学英语单词应用。当前版本提供图片联想、英语发音、例句朗读、学习标记、本地进度保存和自定义图片管理。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可。

## 构建生产版本

```bash
npm run build
npm run preview
```

构建结果位于 `dist`。生产版本支持 PWA，可从手机浏览器添加到主屏幕。

## 添加单词

编辑 `src/words.ts`，按照现有结构添加一条数据。学习进度保存在浏览器 `localStorage` 中。

## 替换图片

点击页面右上角的“管理单词”，为对应单词选择图片。每张图片最大 5 MB，图片存储在项目的 `user-images` 文件夹中。同一台电脑上的不同浏览器访问这个本地服务时会共享图片。
